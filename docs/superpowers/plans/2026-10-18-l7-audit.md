# L7 Self-Audit (mitm) Implementation Plan

> **STATUS (2026-10-19):** fully implemented, all tasks verified on kernel 6.18 (Manjaro); see AGENTS.md and CHANGELOG.md for post-plan fixes.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transparent CA-MITM HTTPS capture proxy + eBPF flow ground-truth daemon that logs every L7 request/response (with PID/UID/comm attribution) to JSONL + body files, on Linux PCs and rooted Android.

**Architecture:** iptables/nftables REDIRECT sends all outbound TCP 443 to a local Go MITM proxy (dynamic CA-signed leaf certs, ALPN h2+http/1.1, upstream re-origination with system-root verification). A CO-RE-free eBPF tracepoint program (`inet_sock_set_state`) emits TCP SYN_SENT flow events with pid/comm; userspace correlates by 4-tuple and flags unproxied flows (cert-pinning suspects). UDP 443 is REJECTed to force QUIC fallback.

**Tech Stack:** Go 1.26, cilium/ebpf, golang.org/x/net/http2, golang.org/x/sys/unix, gopkg.in/yaml.v3, andybalholm/brotli, google/uuid; eBPF side C compiled with clang (vendored bpf_helpers.h, no vmlinux.h — tracepoint ctx structs transcribed from `/sys/kernel/tracing/events/inet/inet_sock_set_state/format`).

**Spec:** `docs/superpowers/specs/2026-10-18-l7-audit-design.md`

## Global Constraints

- Module path: `github.com/hellsing-organization/mitm`
- Go 1.26; only deps listed in Tech Stack; stdlib `testing` only
- `go vet ./...` and `go test ./...` must pass after every task (no root needed for tests)
- eBPF object build (`make bpf`) requires clang; runtime loading requires root — tests must skip gracefully without them
- Upstream TLS is ALWAYS verified against system roots (or injected test pool)
- Bodies are never withheld from forwarding because of capture limits — only storage truncates (`max_body_bytes` default 16777216)
- JSONL events exactly per spec section "Event schema"; types: `flow|http|alert|startup`
- Redirect mark constant: 1337; transparent listen default `127.0.0.1:8080`; default ports `[443]`
- All files compile with no comments unless asked; no emojis
